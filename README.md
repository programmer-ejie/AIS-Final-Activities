# AIS-Final-Activities

Student laboratory materials for Information Assurance and Security 2.

## Download and start

1. Choose **Code > Download ZIP** on GitHub and extract the archive.
2. Open `Lesson 5/Student Exercise`.
3. Read `ACTIVITY.md`, then open `index.html` in a browser.
4. The eight evidence records load automatically; no file selection is needed.
5. Read the completed functions in `service.js`, run the tests, and answer **Guide Questions**. Download your answers before refreshing.

No server or installation is required. All incident records are fictional.

## Repository scope

`AIS2` is the local Git root. Only this README, `.gitignore`, and
`Lesson 5/Student Exercise` are included. The lesson README is also included; other lesson folders remain excluded by `.gitignore`.
